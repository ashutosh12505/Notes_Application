# Notes Application

A full-stack notes management application built with Django REST Framework (backend) and React + Vite (frontend).

## Features

- User authentication with JWT tokens
- Create, view, and delete personal notes
- Secure data isolation (users can only access their own notes)
- Automatic token refresh
- Modern UI with real-time error handling

## Tech Stack

- **Frontend:** React 18 + Vite
- **Backend:** Django REST Framework
- **Authentication:** JWT (JSON Web Tokens)
- **HTTP Client:** Axios
- **Routing:** React Router DOM
